# Benjamin Lopez Snyder

Practice site for voice, sales conduct, and support. Motto: Answer like a person.

## Branches

- `main` is the magazine interview.
- `acid` is the risograph sheet.
- `folio` is the broadcast running order.

## CONTACT_EMAIL

Open `site.js` and set `CONTACT_EMAIL` to a real address. An empty string keeps the contact page on copy-and-show, with no mailto link. A non-empty address adds a mail link on that page.
